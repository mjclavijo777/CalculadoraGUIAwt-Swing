Este proyecto es una calculadora desarrollada en Java con interfaz gráfica (GUI), que permite realizar operaciones matemáticas básicas como:

 Suma
 Resta
 Multiplicación
División

El sistema está estructurado siguiendo el patrón de diseño Modelo–Vista–Controlador (MVC), lo que permite separar la lógica del programa, la interfaz gráfica y el control de las acciones del usuario.
